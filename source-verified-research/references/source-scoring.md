# 信源评分参考

用于专业咨询式行业调研中的信源、信息和证据评分。

## 基础等级

| 等级 | 基础分 | 来源类型 |
|---|---:|---|
| S | 90-100 | 官网、公告、财报、电话会纪要、招股书、监管披露、官方文档、政府/统计机构、原始数据集、官方负责人公开发言 |
| A | 75-89 | 权威研究机构、市场数据机构、方法透明的券商研报、成熟财经/商业媒体、重要行业媒体 |
| B | 55-74 | 垂直行业媒体、会议材料、客户案例、合作伙伴技术文档、招投标公告、专利、招聘信息、有明确作者的技术社区 |
| C | 30-54 | 公众号、自媒体、匿名论坛、转载文章、营销文章、没有原始链接的二手整理。可作为线索或弱证据，缺少高可信来源时可降级使用 |
| D | 0-29 | 打不开的页面、内容农场、无来源说法、明显垃圾内容、伪造引用、无法追溯材料。不得作为正式证据，只可作为继续搜索线索 |

## 加分项

- +5 到 +10：一手来源。
- +3 到 +8：有明确发布时间或事件时间。
- +3 到 +8：主体、地域、单位、口径清楚。
- +3 到 +8：方法、样本、计算方式或定义可见。
- +5 到 +10：被其他高质量独立来源交叉验证。
- +3 到 +5：来自具名官方、专家或机构的直接表述。
- +3 到 +8：明确说明原始出处和原始来源时间。
- +3 到 +8：在同主体、同指标、同口径下提供更新的一手信息。

## 扣分项

- -5 到 -15：广告、公关或营销倾向明显。
- -5 到 -20：二手转载，缺少原始来源。
- -5 到 -20：时间、主体、口径、单位不清楚。
- -5 到 -15：对时效性要求高，但材料明显过旧。
- -10 到 -30：与更高质量证据冲突。
- -20 到 -50：无法打开、无法追溯或疑似伪造。
- -5 到 -15：新文章转述旧数据但未说明原始时间。
- -10 到 -25：媒体或专家表述没有明确来源、口径或可交叉验证材料。

## 时间衰减规则

时间衰减只在同一主体、同一指标或事实、同一口径下使用。不要因为文章发布时间新，就自动提高权重。

必须区分：

- `published_at`：文章或材料发布时间。
- `event_time`：事件发生时间。
- `data_period`：数据所属期间。
- `original_source_time`：被引用或转述的原始来源时间。
- `retrieved_at`：检索时间。

默认优先级：

```text
新的官方/一手来源 > 旧的官方/一手来源
旧的官方/一手来源 > 新的无口径媒体或专家透露
有明确原始出处和口径的新媒体报道 > 无来源的新媒体报道
新文章转述旧数据 = 按旧数据或原始来源时间处理
```

当新媒体披露与旧官方口径冲突时，优先官方口径；只有新披露有清晰来源、明确时间口径且被独立信源支持时，才可提高权重。

## 独立性判断

不要把同一来源链条重复计算为多个独立信源。以下情况通常不算独立：

- 多家媒体转载同一篇通稿。
- 自媒体转述官方公告。
- 研报引用同一篇新闻但没有新增数据。
- 多个网页复制同一段内容。

## 信息与数据口径检查

每条关键信息都要检查：

- 信息类型：事实、数据、判断、披露、预测或推断。
- 主体：信息描述的是谁或什么。
- 时间：发布日期、事件日期、报告期、预测期。
- 地域：全球、中国、某省市、某业务线、某产品线等。
- 单位：金额、百分比、数量、容量、用户数、交易量等。
- 口径：收入还是订单，出货量还是装机量，产能还是可售供给，实际值还是预测值，披露值还是估算值。
- 方法：披露、计算、建模、调研、引用、推断。
- 来源链条：一手来源、转述来源、引用来源或无法追溯来源。

任何字段缺失，都要降低置信度，或把该 claim 标记为 `partial`。

## 低可信来源处理

不要直接丢弃 C 类来源。处理方式：

1. 先作为线索，尝试追溯其原始出处。
2. 如果能追溯到 S/A/B 来源，按原始来源重新评分。
3. 如果无法追溯，但没有更高可信来源，可作为弱证据保留。
4. 使用 C 类来源形成结论时，必须标记为 `weak` 或低置信度，并说明高可信来源缺失。
5. D 类来源不得支撑正式结论，只能提示后续搜索方向。

## 冲突处理

来源冲突时：

1. 优先一手来源。
2. 在同一主体、同一指标和同一口径下，优先更新来源。
3. 优先方法和定义更清楚的来源。
4. 优先独立信源数量更多的一方。
5. 被舍弃或降权的说法仍要写入冲突记录。

不能把不同时间、不同主体、不同单位、不同口径的数据强行合并。
